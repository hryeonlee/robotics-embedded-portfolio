# 통합 시험 기록 — 꼬리 서보 오류

## 1. 현상

팀 통합 코드 실행 중 꼬리 서보가 동작하다 오류(LED 점등)로 멈춤.

## 2. 원인 후보

1. 과부하
2. 과열
3. 전원
4. 통신

## 3. 시험 (2024.06.24 연구노트)

| 후보 | 시험 방법 | 관찰 | 판정 (이 시험 조건 기준) |
|---|---|---|---|
| 과부하 | 걸림 없이 꼬리만 구동 | 오류 지속 | 가능성 낮음 |
| 과열 | 시작 직후 동작 확인 | 시작 직후 오류·LED 점멸 | 가능성 낮음 |
| 전원 | 서보 4개에만 파워서플라이로 별도 공급 | 오류 지속 | 가능성 낮음 |
| 통신 | Arduino Mega에 직접 연결해 전송 | 오류 지속 | 가능성 낮음 |

| 조건 | 결과 |
|---|---|
| 꼬리 1개 (서보 2개) 구동 | 정상 |
| 꼬리 2개 (서보 4개) 연결 | 오류 |

점검 화면의 ID 3: 해당 시점 온도 30.7 °C, 입력 7.6 V, 오류 없음. 서보 전체 또는 다른 조건의 정상 상태로 일반화하지 않음.

과열 조건 시험의 시작 직후 LED 점멸과 통합 동작 중 LED 오류 정지는 서로 다른 관찰 맥락임.

오류 상태 코드를 출력해 서보별 오류를 확인하고, 매뉴얼을 참고해 원인을 좁히려 함.

## 4. 결과

원인 미확정. 조건별 시험으로 원인 가능성을 좁혔고, "서보 4개 동시 구동"이라는 발생 조건까지 확인함.

## 5. 다시 시험한다면

- 통합 전에 최종 구성(서보 4개 동시)으로 먼저 시험.
- "2개 정상 / 4개 오류"처럼 결과가 갈리면 ID, 초기화 순서, 서보 상태 값을 조건별로 바로 기록해 비교.
